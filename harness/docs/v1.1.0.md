# v1.1.0 — 첫 전문가 2명 영입 (2026-09-13)

## 배경

정원을 연 뒤(v1.0.0) 프로젝트가 크게 자랐다. AMOLED-1.75C 에 Brookesia 앱 3개(Claude HUD / Chat /
Settings)가 올라갔고, PC 쪽에 ASP.NET 호스트(`amoled_chat_host`)가 생겨 Whisper STT · 챗 CLI · SAPI TTS 를
BLE 로 기기와 주고받는다. 이 과정에서 사람이 놓쳐 하드웨어가 대신 찾아낸 결함이 반복해서 나왔다.

- 압축 폰트 + 드로우 유닛 2개 → 한글 대부분 깨짐
- NimBLE 호스트 태스크 스택 4 KB 초과 → 답변 재생 중 리부트
- 답변 오디오 단일 버퍼 → 16.8초가 3.6초로 잘림
- `LV_COORD_MAX` 스크롤 오버플로우 → 라벨 뭉개짐
- `LV_EVENT_ALL` 등록 → 버튼 콜백 수백 회 폭주
- 이스케이프된 JSON → 한 줄이 BLE 한 번 쓰기를 초과
- `}` 로 끝나면 완성으로 간주 → 잘린 줄 수용
- MTU 캐시 리셋 → 20바이트 페이로드로 강등

전부 **원인과 증상이 전혀 닮지 않은** 종류다. 그래서 첫 전문가는 이 두 갈래를 맡는다.
